# Financial Performance Analysis | Power BI Project

## Project Overview

This project focuses on analyzing financial transaction data using Microsoft Power BI to evaluate financial performance, monitor key performance indicators (KPIs), and identify trends across customer segments, transaction types, and geographical regions.

The project aims to transform financial and customer data into meaningful business insights through interactive dashboards, data visualization, and financial performance analysis.

## Tools & Technologies

- **Microsoft Power BI** – Interactive dashboards and financial reporting
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – KPI calculations and financial measures
- **Data Modeling** – Establishing relationships between financial transactions and customer data
- **Data Visualization** – Interactive charts, matrices, and analytical reports

## Key Performance Indicators (KPIs)

The project focuses on the following financial performance metrics:

- **Total Transaction Amount:** Total monetary value of financial transactions.
- **Total Transactions:** Number of transactions processed.
- **Average Transaction Value:** Average monetary amount per transaction.
- **Total Fees:** Total fees generated from financial transactions.
- **Total Tax:** Total tax associated with transactions.
- **Year-over-Year (YoY) Growth:** Comparison of financial performance across years.

## Data Analysis

The analysis focuses on:

- **Monthly Transaction Trends:** Examining changes in transaction amounts over time.
- **Transaction Status Analysis:** Comparing successful, failed, and pending transactions.
- **Customer Segment Analysis:** Evaluating financial contributions from Retail, Premium, SME, Corporate, and Wealth customers.
- **Geographical Performance:** Analyzing transaction amounts across different states.
- **Transaction Type Analysis:** Comparing transaction amounts, fees, taxes, and transaction volumes across financial transaction categories.
- **Customer Demographics:** Examining financial transaction distribution by gender.
- **Year-over-Year Analysis:** Monitoring changes in transaction performance across different years.

## Dashboard Features

- Interactive financial performance dashboard with KPI indicators.
- Monthly transaction trend visualization.
- Transaction status and customer segment comparisons.
- State-level financial performance analysis.
- Transaction type analysis using matrix visualizations.
- Dynamic filtering by year, occupation, category, and selected measures.
- Detailed transaction records with drill-down capabilities.

## Project Highlights

- Used DAX measures to support financial KPI calculations.
- Designed interactive visualizations for financial and customer analysis.
